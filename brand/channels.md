# Channels

> You chose "all". Posting on every channel from day one with no tools means burning out by week 3.
> **Recommendation:** start with the 3 marked ★ (best fit for a B2B software services company). Turn the rest on once the loop is running.
> Set `Active` to yes or no.

| Channel | Active | Posts / week | Format notes |
|---|---|---|---|
| ★ LinkedIn | yes | 3 | 150–300 words. Hook in the first 2 lines (shown before "see more"). Text posts and carousels do best. Link goes in the first comment, not the post. |
| ★ Email newsletter | yes | 1 | 300–600 words, one topic, one CTA. Subject line under 50 chars. Needs an email tool later (e.g. free tier of Brevo or MailerLite). |
| ★ Blog / website | yes | 1 | 800–1500 words, SEO title, answers one question buyers search for. Reused as source material for the other channels. |
| X / Twitter | no | 5 | Under 280 chars, or a thread of 4–7 posts. |
| Facebook | no | 3 | Shorter than LinkedIn, more casual. Good for local SMB audiences. |
| Instagram | no | 3 | Carousel or reel. Caption under 150 words. Needs visuals, so Claude writes a visual brief. |
| TikTok / YouTube Shorts / Reels | no | 2 | 30–60s script with hook (first 3s), body and CTA. Claude writes the script and shot list. |
| WhatsApp Status / Channel | no (recommended next) | 3 | Very short, direct. Strong in East African markets, and WhatsApp is already Oveliq's main contact route. |

## Repurposing rule
One core idea → blog post → LinkedIn post + email + (when active) short-video script + X thread.
Each channel version is a separate Trello card.
