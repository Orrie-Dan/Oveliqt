# Weekly review

1. Load `data/results.csv` and the `content/` files for the posts in it.
2. Compare performance by channel, content-mix category, hook style, topic and CTA type.
   Rank by **leads, then calls, then sales first**, with clicks and engagement only as tie-breakers. Likes don't pay bills.
3. Be honest about sample size: with fewer than ~10 posts per pattern, call findings "early signals", not conclusions.
4. Write `insights/YYYY-MM-DD.md`:
   - **Double down:** 2–3 patterns that led to leads or clicks
   - **Stop / change:** 1–2 patterns that underperformed
   - **Test next week:** 1–2 specific experiments
   - **Next week's plan:** suggested number of posts per channel and topic themes
5. `/research` and `/draft` read the newest insights file, which closes the loop. Summarise the file for the user.
